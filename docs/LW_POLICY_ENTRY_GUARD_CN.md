# LW-080 真机策略启动姿态检查

仅真机 `rl_real_LW` 启用；仿真、主机测算默认不启用。

GetUp_Leg完成后进入leg_loco、GetUp_Wheel完成后进入wheel_loco时，必须满足：

- 横滚和俯仰绝对值分别不超过8°；偏航不参与检查。
- GetUp完成后，新的有效IMU样本持续满足角度条件至少0.5秒。
- 数据不得过期、来自未来或出现超过trusted_imu_timeout的样本间隔；失效/超限重新计时。

配置位于policy/LW/base.yaml：

```yaml
policy_entry_angle_deg: 8.0
policy_entry_stable_time: 0.5
```

缺省值亦为8°和0.5秒。角度必须有限且在(0,90)度内，时间必须有限且大于零。该角度范围是配置有效性约束，并非所有取值都经过实机验证。

不满足条件时按启动键，会拒绝该次请求、保持GetUp并每0.5秒打印一次警告，包含策略、角度、阈值、稳定时间和原因。满足条件后打印“已满足启动条件，请重新按键启动策略”，停止重复警告。不会保存请求等待自动启动；需再次明确输入启动命令。

在请求切换和下一控制周期真正执行切换前各检查一次，避免两周期之间出现尖峰后仍激活策略。重新进入GetUp会清空稳定记录。GetDown/Passive通道继续有效，原有更高优先级传感器失效与姿态保护仍可执行其安全处置。

本功能只限制启动时机，不是IMU校准或尖峰滤波，不保护启动后的全部异常，也不能识别角度正常但角速度异常。水平数据有误时仍可能误判；已分析的轮式振荡启动前姿态约0.8°横滚、2.7°俯仰，因此不能靠本保护保证解决该振荡。

修改后需构建新的真机部署包才会生效；旧部署包不会被源码修改自动更新。本项离线验证不代表已完成实机验收。
